AI.SPIRE Vehicle Manual RAG
Problem Pipeline Demo Run Locally

Arabic answers from vehicle manuals, with page-grounded citations.

A local Docker Compose RAG system that ingests translated Arabic vehicle manuals, chunks them by page, embeds them with a multilingual model, and retrieves grounded answers through Chroma and PostgreSQL.

Run with Docker Compose View Example

Project Goal

Vehicle owners often need fast answers from long manuals, and Arabic support is especially important for local users. This project turns translated manual JSON files into searchable, citation-ready knowledge for an Arabic assistant.

Input

Page-aware Arabic JSON manuals in data/translated_manuals/.

Retrieval

Multilingual embeddings stored in Chroma with metadata filters.

Answering

FastAPI RAG endpoint returns grounded answers and manual/page citations.

Ingestion Pipeline

The ingestion script starts after parsing, OCR, language detection, and translation are already complete.

01Validate translated JSON
02Normalize Arabic text
03Create page-aware chunks
04Extract metadata
05Generate multilingual embeddings
06Upsert vectors into Chroma
07Save metadata in PostgreSQL
08Serve answers through RAG

Example Interaction

The assistant retrieves chunks from the matching manual and cites the source page.

Technology Stack

Backend

FastAPI, Python, SQLAlchemy-ready PostgreSQL metadata storage.

Vector Search

Chroma collection with deterministic chunk IDs and filterable metadata.

Embeddings

Sentence Transformers multilingual embeddings for Arabic and English queries.

Run Locally

The project is designed for the Proficient submission path: a local Docker Compose system plus this public GitHub Pages artifact. 

docker compose up
docker compose exec backend python scripts/ingest_translated_manuals.py

Dry Run

Validate, normalize, and chunk manuals without writing to Chroma or PostgreSQL. 

docker compose exec backend python scripts/ingest_translated_manuals.py --dry-run

GitHub Pages Setup

In repository settings, choose Pages, deploy from branch, and select the /docs folder.
