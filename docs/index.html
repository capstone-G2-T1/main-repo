Built for real manual support.

Dalilak helps users ask natural Arabic questions about vehicle warnings, maintenance, battery issues, brakes, and settings, then verifies every answer.

01

Arabic-first assistant

Questions can be written naturally in Arabic, including mixed car terms and warning descriptions.

02

Manual-grounded search

Translated JSON manuals are cleaned, chunked by page, embedded, and retrieved through Chroma.

03

Source discipline

Answers include manual name, file, page number, and citation metadata instead of unsupported guesses.

Ingestion pipeline

The portfolio artifact highlights the backend work that makes Dalilak searchable and citation-ready.

STEP 01

Validate

Read translated manual JSON and skip invalid, empty, or page-number-only records.

STEP 02

Normalize

Clean Arabic text, HTML fragments, image markers, and noisy OCR/translation leftovers.

STEP 03

Chunk

Create page-aware chunks with deterministic IDs, overlap, source file, and section titles.

STEP 04

Store

Generate multilingual embeddings and save vectors plus metadata in Chroma and PostgreSQL.
